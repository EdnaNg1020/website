# 登入頁面重定向實施計劃

## 任務概述
為 `_4/code.html` 登入頁面添加重定向功能，使 Google 登入按鈕點擊後跳轉至 `_8/code.html` 儀表板頁面。

## 當前狀態分析

### 登入頁面 (`_4/code.html`)
- 位置：`_4/code.html`
- 功能：茶數據分析系統後台登入頁面
- 當前問題：Google 登入按鈕無功能
- 按鈕位置：第 74-82 行
- 按鈕 HTML：
```html
<button class="w-full bg-white border border-gray-300 rounded-full flex items-center justify-center gap-3 py-3 px-4 shadow-sm active:scale-[0.98] transition-all hover:bg-gray-50">
```

### 儀表板頁面 (`_8/code.html`)
- 位置：`_8/code.html`
- 功能：完整的數據分析儀表板
- 特點：包含首頁和分析頁面切換功能
- 導航：使用 `#analysis-view` 錨點進行頁面內切換

## 實施方案

### 方案一：簡單重定向（推薦）
1. **修改登入按鈕**：
   - 添加 `id="google-login-btn"` 屬性
   - 添加 `onclick="handleGoogleLogin()"` 事件處理器

2. **添加 JavaScript 功能**：
   - 在 `</body>` 標籤前添加 `<script>` 標籤
   - 實現 `handleGoogleLogin()` 函數
   - 使用 `window.location.href = '../_8/code.html'` 進行重定向

3. **添加加載狀態**：
   - 點擊時顯示加載動畫
   - 防止重複點擊

### 方案二：模擬登入流程
1. **添加登入模擬**：
   - 點擊後顯示「登入中...」狀態
   - 1.5 秒延遲後重定向
   - 模擬真實登入體驗

2. **錯誤處理**：
   - 添加基本的錯誤處理
   - 重定向失敗時顯示錯誤訊息

## 具體修改步驟

### 步驟 1：修改登入按鈕
```diff
- <button class="w-full bg-white border border-gray-300 rounded-full flex items-center justify-center gap-3 py-3 px-4 shadow-sm active:scale-[0.98] transition-all hover:bg-gray-50">
+ <button id="google-login-btn" onclick="handleGoogleLogin()" class="w-full bg-white border border-gray-300 rounded-full flex items-center justify-center gap-3 py-3 px-4 shadow-sm active:scale-[0.98] transition-all hover:bg-gray-50">
```

### 步驟 2：添加 CSS 加載狀態樣式
在 `<style>` 標籤中添加：
```css
.loading {
    opacity: 0.7;
    cursor: not-allowed;
}

.loading-spinner {
    display: inline-block;
    width: 16px;
    height: 16px;
    border: 2px solid rgba(255,255,255,.3);
    border-radius: 50%;
    border-top-color: #4285F4;
    animation: spin 1s ease-in-out infinite;
}

@keyframes spin {
    to { transform: rotate(360deg); }
}
```

### 步驟 3：添加 JavaScript 功能
在 `</body>` 標籤前添加：
```html
<script>
function handleGoogleLogin() {
    const btn = document.getElementById('google-login-btn');
    const originalText = btn.innerHTML;
    
    // 防止重複點擊
    if (btn.classList.contains('loading')) return;
    
    // 添加加載狀態
    btn.classList.add('loading');
    btn.innerHTML = `
        <div class="loading-spinner"></div>
        <span class="text-sm font-semibold text-gray-700 ml-2">登入中...</span>
    `;
    btn.disabled = true;
    
    // 模擬登入延遲（可選）
    setTimeout(() => {
        // 重定向到儀表板
        window.location.href = '../_8/code.html';
    }, 800); // 800ms 延遲模擬登入過程
}

// 可選：添加 Enter 鍵支援
document.addEventListener('DOMContentLoaded', function() {
    const btn = document.getElementById('google-login-btn');
    btn.addEventListener('keypress', function(e) {
        if (e.key === 'Enter') {
            handleGoogleLogin();
        }
    });
});
</script>
```
