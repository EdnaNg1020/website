返回按鈕功能測試

測試步驟：

  1. 點擊下方"前往PDF報告頁面"按鈕
  2. 在PDF報告頁面中，點擊左上角的返回箭頭
  3. 檢查是否能成功返回此頁面
  4. 點擊下方"測試返回邏輯"按鈕檢查代碼

測試結果：

點擊按鈕開始測試...

技術說明：

返回按鈕的代碼邏輯：

if (history.length > 1) {
    history.back();
} else {
    window.location.href = '../_10/code.html';
}

這確保了：

  • 如果有瀏覽歷史，則返回上一頁
  • 如果沒有歷史（直接打開頁面），則導航到客戶資料庫頁面
  • 添加了錯誤處理以防萬一
